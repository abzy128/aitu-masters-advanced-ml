Fraud Detection in Financial Transactions

Using Isolation Forest on Credit Card Fraud Dataset

Group AAI-2501M

Advanced Machine Learning

Introduction

  • Credit card fraud causes >$30 billion in global losses annually
  • Digital payments expansion increases the attack surface
  • Traditional rule-based systems struggle with evolving fraud patterns
  • Key challenge: extreme class imbalance — fraud is <0.2% of transactions
  • Goal: Apply unsupervised anomaly detection to identify fraudulent transactions without labeled training data

Dataset

Credit Card Fraud Detection (Kaggle/ULB)

  • 284,807 transactions over 2 days
  • 30 features
  • European cardholders, Sept 2013
  • Train/test: 80/20 (stratified)

V1–V28 PCA-transformed (anonymized)

Technology: Isolation Forest

How It Works

  • Unsupervised anomaly detection algorithm
  • Builds ensemble of random isolation trees
  • Recursively partitions feature space with random splits
  • Anomalies are few and different → isolated in fewer splits
  • Shorter path length = more anomalous

Why Isolation Forest?

  • No labeled data required for training
  • Naturally handles extreme class imbalance
  • Linear time complexity — suitable for real-time
  • Competitive with supervised methods on this dataset (Alarfaj et al., 2022)

Key Parameter

contamination = 0.0017 (matched to fraud ratio)

Conclusion

  • ROC-AUC of 0.9539 confirms strong anomaly scoring capability
  • Low F1 (0.29) reflects inherent limitation of purely unsupervised detection on 0.17% fraud rate
  • Very low false positive rate (0.14%) is valuable for production systems
  • Best used as a first-line pre-filter or feature generator for downstream supervised models
  • Improvement paths:
    • Hybrid approach: IF scores as features for supervised classifier (+10–20% F1)
    • Extended Isolation Forest for correlated features
    • Threshold optimization on validation set
