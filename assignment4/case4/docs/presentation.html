Using Random Forest Classifier on UNSW-NB15 Dataset

Introduction

  • Increasing sophistication of cyber attacks demands automated intrusion detection
  • Signature-based systems fail against novel and zero-day threats
  • ML-based anomaly detection can generalize to unseen attack patterns
  • Ensemble methods (Random Forest, Gradient Boosting) consistently top benchmarks (Ahmad et al., 2021)
  • Goal: Binary classification of network traffic as normal or attack using Random Forest

Dataset

UNSW-NB15 (Moustafa & Slay, 2016)

  • Modern benchmark for network IDS
  • Realistic traffic with 9 attack categories
  • 42 features after preprocessing
  • Pre-defined train/test splits
  • More challenging than KDD'99 / NSL-KDD

Technology: Random Forest

How It Works

  • Ensemble of decision trees via bagging
  • Each tree trained on bootstrap sample
  • Random feature subsets at each split
  • Final prediction: majority vote
  • Built-in feature importance (Gini)

Why Random Forest?

  • Top-3 ML algorithm for NIDS (Ahmad et al., 2021)
  • Handles mixed feature types natively
  • Robust to overfitting
  • ROC-AUC ~0.97–0.98 on UNSW-NB15 (Ferrag et al., 2020)

Configuration

200 trees, max depth 20, min samples split 5

Conclusion

  • ROC-AUC of 0.9827 and 98.8% attack recall — virtually all attacks detected
  • Results match published benchmarks: Ferrag et al. (2020) report AUC 0.97–0.98, F1 0.88–0.90
  • Accuracy of 87% consistent with Kanna & Santhi (2021): 87–89% for RF on UNSW-NB15
  • TTL-based features dominate importance — attack tools generate distinctive TTL values
  • Trade-off: high recall (miss few attacks) vs. moderate precision (some false alarms) — acceptable for security
  • Future work: multi-class attack classification, feature selection, comparison with XGBoost/DL
